## 📌 Features

- **Menu Management**: Add delicious dishes with name, price, description, category, and photo.
- **Image Upload to Cloud**: Sends images to the Spring Boot backend, which seamlessly stores them in Amazon S3.
- **Food List**: View active food items and delete expired or out-of-stock items.
- **Order Management**: Monitor all incoming customer orders, review delivery addresses, and advance order statuses ("Food Processing" ➔ "Out for Delivery" ➔ "Delivered").


### 2. Run Development Server

