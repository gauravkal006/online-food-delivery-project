## 📌 Features

- **Food Discovery**: Interactive category filter to discover tasty dishes (Salad, Rolls, Deserts, Sandwich, Cake, Pure Veg, Pasta, Noodles).
- **Persistent Cart**: Synced with MongoDB for authenticated customers with instant item increment/decrement.
- **Secure Payment Checkout**: Integrated with Razorpay checkout popup supporting UPI, Cards, NetBanking, and Wallets.
- **Order Tracking**: Real-time status inspection for customer orders ("Food Processing", "Out for Delivery", "Delivered").
- **JWT Authentication**: Smooth modal login and account creation with token storage.
